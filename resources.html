VASP Postprocessing Suite

VaspViz is a desktop application I developed for postprocessing VASP (Vienna Ab initio Simulation Package) output files. It provides an intuitive interface for visualizing band structures, density of states (DOS), electronic properties, and equation of state fits — without needing to write a single line of script. Built for physicists and computational materials scientists.
